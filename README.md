# الحي الثلجي

- G: ركوب أقرب حصان أو النزول.
- Q: التبديل بين اليد/الفأس والقوس والرمح المصنوعين.
- نقرة بالماوس: إطلاق سهم أو طعن بالرمح؛ أثناء البناء تثبت القطعة.
- Tab: الحقيبة وصناعة الأسلحة والسهام والأدوات.
- B: البناء، R: تدوير القطعة، Esc: إلغاء.
- E: جمع الموارد والتفاعل مع الباب والنار والصيد القريب.
- F: أكل اللحم المطبوخ.
- V: الإعدادات والمنظور الأول أو الثالث.
- WASD: حركة، Shift: ركض أو عدو الحصان.

الحي يستخدم ملف Trailer Park in Winter مع نسب العمل لصاحبه ورخصة CC BY 4.0. البيوت مسح خارجي وليست غرفًا قابلة للدخول. مسارات التصادم تقريبية محسوبة من سطح الخريطة. الأحصنة والأسلحة نماذج هندسية بسيطة منشأة لهذه اللعبة.
حفظ المدينة منفصل عن حفظ الغابة. اللعبة ما زالت لاعبًا واحدًا.

التحقق المحلي: 23 اختبارًا للمدينة والركوب والأسلحة والحفظ؛ 32 اختبارًا للموارد والبناء والأبواب والطبخ واسترجاع الحفظ. فحص الصياغة البرمجية ومعاينة المنظور الثالث والركوب.
